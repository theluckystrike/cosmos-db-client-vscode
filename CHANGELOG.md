# Changelog

## 0.1.0 (2026-11-10)

First release.

- Connect with a connection string, an endpoint and key, the local emulator in one click, or Microsoft Entra ID. Keys in VS Code secret storage.
- Explorer: databases, containers (partition key, throughput, indexing policy), stored procedures, triggers, user-defined functions.
- NoSQL queries with parameters, page size and partition scope; request units and query metrics on every page; Load more through the continuation token; Load all with Stop.
- Virtualized grid and JSON view, detail pane, autocomplete of property names from a 100-item sample.
- Items open as JSON and save with an ETag check; create with a partition key prompt; delete with a confirmation.
- Exact numbers: values beyond JavaScript's safe range keep every digit and show a warning badge.
- Streamed export to JSON, JSONL and CSV; import of JSON and JSONL with bulk writes, progress and a running RU total.
- Read-only switch per connection.
- Zovo Pro (3 free tries each): Query Cost Report with indexing advice, Copy Container to another account.
